1 Introduction

2 Naive set theory

We begin with two primitive informal notions: objects and sets. Roughly speaking, a set is a collection of objects, and the most basic question we can ask is whether a given object belongs to a given set. If the object \(x\) belongs to the set \(A\), we write \[ x\in A, \] and if it does not belong to \(A\), we write \[ x\notin A. \]

An intuitive example of set is given by the set of natural numbers \[ \mathbb{N}=\{0,1,2,3,\dots\}, \] which, at this stage, should be understood only informally.

WarningNumbers will NOT be built

Remark 1. In this course, we will unfortunately not build the set of natural numbers \(\mathbb{N}\), of integers \(\mathbb{Z}\), of rational numbers \(\mathbb{Q}\), or of real numbers \(\mathbb{R}\) from scratch.

Doing so carefully would be supremely satisfying from the intellectual point of view, but it would also require a substantial amount of additional time to go through a similarly substantial amount of foundational material.

In any case, we will explicitly point out the properties and subtleties of these number systems whenever they become relevant.

This informal viewpoint is useful, but also delicate. If one tries to take the notion of set completely literally and declare that every possible collection of objects is automatically a set, contradictions appear. The most famous one is Russell’s paradox, which can be explained through the barber’s paradox: imagine a barber who lives in a village and shaves exactly those people in the village who do not shave themselves. Does the barber shave himself? If he does, then by definition he should not; if he does not, then by definition he should. The set-theoretic Russel’s paradox has the same logical flavour and warns us that foundations must be handled with care. Taking that issue seriously would force us into a long discussion on logic and the foundations of mathematics, which is far beyond the scope of this course. So we adopt a pragmatic axiomatic point of view.

In these notes, we work with objects and sets, and we regard every set as an object. However, not every object is automatically considered to be a set. For instance, the number \(42\) is an object, but Axiom 4 below assures there is set \(\{42\}\) containing the number 42, which is also an object.

NoteAxioms of Set Theory

  1. Sets Are Objects: Every set is an object.

  2. Equality of Sets: Two sets \(A\) and \(B\) are said to be equal if they have exactly the same elements, that is, if for every object \(x\) one has \[ x\in A \Longleftrightarrow x\in B. \] Thus, when dealing with sets, what matters is not the order in which the elements are written, nor how many times they are listed, but only which objects belong to the set.

  3. Empty Set: There exists a set with no elements, called the empty set and denoted by \[ \emptyset=\{\}. \]

  4. Singleton sets and pair sets: If \(x\) is an object, then there exists a set whose only element is \(x\). This set is called the singleton associated with \(x\) and is denoted by \[ \{x\}. \] If \(x\) and \(y\) are objects, then there exists a set whose elements are exactly \(x\) and \(y\). This set is denoted by \[ \{x,y\}. \] If \(x=y\), this is just the singleton \(\{x\}\).

  5. Pairwise Union: If \(A\) and \(B\) are sets, then there exists a set whose elements are precisely those objects that belong to \(A\) or to \(B\). This set is called the union of \(A\) and \(B\) and is denoted by \[ A\cup B. \]

  6. Specification: Let \(A\) be a set, and let \(P(x)\) be a property referring to objects \(x\). Then there exists a set consisting of exactly those elements of \(A\) for which \(P(x)\) is true. We denote it by \[ \{x\in A \,:\, P(x)\}. \] This is the basic operation that allows us to carve out subsets from sets that already exist.

  7. Replacement: Let \(A\) be a set, and suppose that to each element \(x\in A\) we assign a unique object \(f(x)\). Then the collection of all such outputs \[ \{f(x)\,:\, x\in A\} \] is again a set. This axiom says that if we start with a set and systematically replace each of its elements by another object, the resulting collection is still a set.

  8. Natural Numbers: There exists a set \(\mathbb{N}\) whose elements are called the natural numbers, together with a distinguished element \(0\in\mathbb{N}\) and a successor operation \[ n\mapsto n+1 \] which sends each natural number to another natural number.

  9. Power set:

The previous axioms are enough for the level of set theory we need in this course.

NoteSubset

Definition 1 Given two sets \(A\) and \(X\), we write \[ A\subseteq X \] if every element of \(A\) is also an element of \(X\). In this case, we call \(A\) a subset of \(X\).

If \(A\neq X\), which means there is at least one element of \(X\) that is not in \(A\), we say \(A\) is a strict subset, and write \(A\subset X\).

NoteIntersection

Definition 2 If \(A\) and \(B\) are subsets of \(X\), we define their intersection is the set \[ A\cap B:=\{x\in A \,:\, x\in B\}. \]

NoteDifference and complement set

Definition 3 If \(A\) and \(B\) are subsets of \(X\), their difference is the set \[ A\setminus B:=\{x\in A \,:\, x\notin B\}. \]

In particular, when \(A=X\), the difference \(X\setminus B\) is called the complement of \(B\) in \(X\), and it is often denoted as \(B^{c}\) when \(X\) is understood from the context.

NoteCartesian product

Definition 4 For two sets \(A\) and \(B\), their Cartesian product is the set \[ A\times B:=\{(a,b)\,:\, a\in A,\ b\in B\}. \] Here \((a,b)\) denotes the ordered pair formed by \(a\) and \(b\).

More generally, if \(A_{1},\dots,A_{n}\) are sets, we define their finite Cartesian product by \[ \prod_{j=1}^{n}A_{j} := \left\{(x_{1},\dots,x_{n})\,:\, x_{j}\in A_{j}\ \mbox{ for every } j=1,\dots,n\right\}. \]

WarningOrdered pairs

Remark 2. In order for Definition 4 to actually make sense, we must be able to consider \((a,b)\) an object, and to be sure that \((a,b)\) is the same object as \((a',b')\) if and only if \(a=a'\) and \(b=b'\).

To do this, we need the so-called Kuratowski’s definition of ordered pairs, which defines \[ (a,b):=\{\{a\},\{a,b\}\}. \]

NoteRelation on a set

Definition 5 Let \(X\) be a set. A relation on \(X\) is a subset \[ R\subseteq X\times X. \] If \((x,y)\in R\), we often write \[ x\,R\,y. \]

Thus, a relation is simply a systematic way of declaring, for some ordered pairs \((x,y)\) of elements of \(X\), that \(x\) is related to \(y\).

NoteOrder relations

Definition 6 Let \(X\) be a set, and let \(\leq\) be a relation on \(X\). We say that \(\leq\) is a partial order if the following properties hold for every \(x,y,z\in X\):

  1. Reflexivity: \(x\leq x\).
  2. Antisymmetry: if \(x\leq y\) and \(y\leq x\), then \(x=y\).
  3. Transitivity: if \(x\leq y\) and \(y\leq z\), then \(x\leq z\).

If, in addition, for every \(x,y\in X\) one has either \(x\leq y\) or \(y\leq x\), then \(\leq\) is called a total order or linear order.

When the order is total, we also write \[ x<y \] to mean that \(x\leq y\) and \(x\neq y\).

NoteUpper and lower bounds

Definition 7 Let \(X\) be a totally ordered set, and let \(A\subseteq X\).

An element \(u\in X\) is called an upper bound for \(A\) if \[ a\leq u \] for every \(a\in A\).

An element \(\ell\in X\) is called a lower bound for \(A\) if \[ \ell\leq a \] for every \(a\in A\).

An upper bound \(s\) for \(A\) is called the least upper bound or supremum of \(A\) if \[ s\leq u \] for every upper bound \(u\) of \(A\).

A lower bound \(m\) for \(A\) is called the greatest lower bound or infimum of \(A\) if \[ \ell\leq m \] for every lower bound \(\ell\) of \(A\).

If \(A\) has a least upper bound, we write \[ \sup A. \] If \(A\) has a greatest lower bound, we write \[ \inf A. \]

A totally ordered set is said to have the least-upper-bound property if every nonempty subset which is bounded above has a supremum.

NoteField

Definition 8 A field is a set \(F\) endowed with two operations, called addition and multiplication, together with two distinguished elements \(0,1\in F\) with \(0\neq 1\), such that the following hold for every \(x,y,z\in F\):

  1. Associativity of addition and multiplication: \[ (x+y)+z=x+(y+z),\qquad (xy)z=x(yz). \]

  2. Commutativity of addition and multiplication: \[ x+y=y+x,\qquad xy=yx. \]

  3. Neutral elements: \[ x+0=x,\qquad x\cdot 1=x. \]

  4. Additive inverses: for every \(x\in F\), there exists an element \(-x\in F\) such that \[ x+(-x)=0. \]

  5. Multiplicative inverses: for every \(x\in F\) with \(x\neq 0\), there exists an element \(x^{-1}\in F\) such that \[ x\,x^{-1}=1. \]

  6. Distributive law: \[ x(y+z)=xy+xz. \]

These axioms allow us to perform the usual algebraic manipulations with sums, differences, products, and quotients by nonzero elements. The familiar number systems \(\mathbb{Q}\) and \(\mathbb{R}\) are examples of fields.

NoteOrdered field

Definition 9 An ordered field is a field \(F\) in the sense of Definition 8, together with a total order \(\leq\) (with associated strict order \(<\)), such that

  1. if \(x<y\), then \[ x+z<y+z \] for every \(z\in F\);
  2. if \(0<x\) and \(0<y\), then \[ 0<xy. \]

Thus, an ordered field is a field in which the algebraic operations and the order relation are compatible. The rational numbers \(\mathbb{Q}\) and the real numbers \(\mathbb{R}\) are the standard examples.

NoteCharacterization of the real numbers

Theorem 1 There exists, up to order-preserving field isomorphism, only one ordered field with the least-upper-bound property. That ordered field is what mathematicians call the set of real numbers, and it can be proved to “coincide” with the intuitive idea we already have of \(\mathbb{R}\).

We will not prove this theorem here. Instead, we simply accept that the familiar real numbers form an ordered field with the least-upper-bound property and use that fact throughout the course.

NoteThe standard number sets inside \(\mathbb{R}\)

Definition 10 Once \(\mathbb{R}\) is in place, we regard the standard number systems as nested subsets \[ \mathbb{N}\subseteq \mathbb{Z}\subseteq \mathbb{Q}\subseteq \mathbb{R}. \] Here \(\mathbb{N}\) denotes the natural numbers, \(\mathbb{Z}\) the integers, \(\mathbb{Q}\) the rational numbers, and \(\mathbb{R}\) the real numbers.

We will use these inclusions in the usual informal way and think of the algebraic operations and the order on the smaller number sets as inherited from \(\mathbb{R}\).

NoteInduction principle

Proposition 1 Let \(P(n)\) be a statement depending on a natural number \(n\in\mathbb{N}\). Assume that

  1. \(P(0)\) is true;
  2. whenever \(P(n)\) is true, then \(P(n+1)\) is also true.

Then \(P(n)\) is true for every \(n\in\mathbb{N}\).

This is the principle of mathematical induction. In practice, it allows us to prove infinitely many statements, one for each natural number, by verifying only a base case and one inductive step.

3 Functions

Just as relations are special subsets of Cartesian products, functions may be regarded as special relations in which each input determines exactly one output.

NoteFunctions as relations

Definition 11 Let \(D,X,Y\) be sets with \(D\subseteq X\). A function from \(D\) to \(Y\) is a relation \[ f\subseteq D\times Y \] such that for every \(x\in D\) there exists a unique \(y\in Y\) with \[ (x,y)\in f. \]

In this situation, we write \[ f\colon D\subseteq X\rightarrow Y \] and denote by \(f(x)\) the unique element \(y\in Y\) such that \((x,y)\in f\). The set \(D\) is called the domain of \(f\), while \(Y\) is called the codomain of \(f\).

NoteEquality of functions

Definition 12 Two functions \[ f\colon D\subseteq X\rightarrow Y \qquad\text{and}\qquad g\colon E\subseteq X'\rightarrow Y' \] are said to be equal if \[ D=E,\qquad Y=Y', \] and \[ f(x)=g(x) \] for every \(x\in D\).

Thus, the domain and codomain are part of the data of a function. In particular, the same explicit rule applied to different domains defines different functions. For example, the functions \[ f\colon \mathbb{R}\rightarrow\mathbb{R},\qquad f(x)=x^{2}, \] and \[ g\colon [0,+\infty)\rightarrow\mathbb{R},\qquad g(x)=x^{2}, \] are not equal because their domains are different.

NoteComposition of functions

Definition 13 Consider two functions \[ f\colon D\subseteq X\rightarrow Y \qquad\text{and}\qquad g\colon E\subseteq Y\rightarrow Z. \] Assume that \[ f(x)\in E \] for every \(x\in D\). Then the composition of \(g\) and \(f\) is the function \[ g\circ f\colon D\subseteq X\rightarrow Z \] defined by \[ (g\circ f)(x):=g(f(x)). \]

NoteAssociativity of function composition

Proposition 2 Let \[ f\colon D\subseteq X\rightarrow Y,\qquad g\colon E\subseteq Y\rightarrow Z,\qquad h\colon F\subseteq Z\rightarrow W \] be functions such that the compositions involved are well defined. Then \[ h\circ (g\circ f)=(h\circ g)\circ f. \]

Proof: Both sides are functions from \(D\) to \(W\). For every \(x\in D\), one has \[ \bigl(h\circ (g\circ f)\bigr)(x)=h\bigl((g\circ f)(x)\bigr)=h(g(f(x))), \] while \[ \bigl((h\circ g)\circ f\bigr)(x)=(h\circ g)(f(x))=h(g(f(x))). \] Hence the two functions have the same domain, the same codomain, and the same values on every point of the domain. By Definition 12, they are equal.
WarningHow we will write functions

Remark 3. Sometimes, we may be forced to talk about the function \(f\colon D\subseteq X\rightarrow Y\) given by \(f(x)=y\) multiple times when proving a theorem, solving an exercise, or discussing an idea. To avoid an absurd amount of notationally-heavy repetitions, once the domain, the input space, the output space, and the explicit rule \(f(x)=y\) have been clearly defined as above, we will often write just \(f(x)=y\), or even just \(f\), for the rest of the proof of the theorem, or of the exercise, or of the discussion.

Moreover, sometimes we may be introducing a subset \(D\subseteq X\), and later introduce a function having \(D\) as domain. In this case, we often writes \(f\colon D\rightarrow Y\) given by \(f(x)=y\) omitting the input space since it is clear from the context.

NoteInjective, surjective, and bijective functions

Definition 14 Consider the function \[ f\colon D\subseteq X\rightarrow Y. \]

We say that \(f\) is injective if \[ f(x)=f(x') \Longrightarrow x=x' \] for every \(x,x'\in D\).

We say that \(f\) is surjective if for every \(y\in Y\) there exists \(x\in D\) such that \[ f(x)=y. \]

We say that \(f\) is bijective if it is both injective and surjective.

NoteImage and inverse image

Definition 15 Consider the function \[ f\colon D\subseteq X\rightarrow Y. \]

If \(A\subseteq D\), the image of \(A\) through \(f\) is the subset of \(Y\) defined by \[ f(A):=\{f(x)\,:\, x\in A\}. \]

If \(B\subseteq Y\), the inverse image of \(B\) through \(f\) is the subset of \(D\) defined by \[ f^{-1}(B):=\{x\in D \,:\, f(x)\in B\}. \]

In particular, the image of the whole domain is \[ f(D)=\{f(x)\,:\, x\in D\}\subseteq Y. \] Thus, the function \(f\) is surjective if and only if \[ f(D)=Y. \]

Note that the notation \(f^{-1}(B)\) for inverse image makes sense whether or not the function \(f\) admits an inverse function.

NoteLeft inverse, right inverse, and inverse function

Definition 16 Let \[ f\colon D\subseteq X\rightarrow Y. \] The identity function on \(D\) is the function \[ \mathrm{id}_{D}\colon D\rightarrow D \] defined by \[ \mathrm{id}_{D}(x)=x. \]

A function \[ g\colon Y\rightarrow D \] is called a left inverse of \(f\) if \[ g\circ f=\mathrm{id}_{D}. \]

A function \[ h\colon Y\rightarrow D \] is called a right inverse of \(f\) if \[ f\circ h=\mathrm{id}_{Y}. \]

If a function \(u\colon Y\rightarrow D\) is both a left inverse and a right inverse of \(f\), then \(u\) is called the inverse function of \(f\) and is denoted by \[ f^{-1}\colon Y\rightarrow D. \] In that case, \[ f^{-1}\circ f=\mathrm{id}_{D} \qquad\text{and}\qquad f\circ f^{-1}=\mathrm{id}_{Y}. \]

NoteBasic properties of inverses

Proposition 3 Let \[ f\colon D\subseteq X\rightarrow Y. \]

  1. If \(f\) admits a left inverse, then \(f\) is injective.
  2. If \(f\) admits a right inverse, then \(f\) is surjective.
  3. If \(f\) admits both a left inverse and a right inverse, then they coincide.
  4. The function \(f\) admits an inverse function if and only if it is bijective.
  5. If the inverse function exists, then it is unique, it is bijective, and \[ \left(f^{-1}\right)^{-1}=f. \]
Proof:

Suppose first that \(g\colon Y\rightarrow D\) is a left inverse of \(f\). If \(f(x)=f(x')\), then \[ x=(g\circ f)(x)=g(f(x))=g(f(x'))=(g\circ f)(x')=x', \] so \(f\) is injective.

Now suppose that \(h\colon Y\rightarrow D\) is a right inverse of \(f\). For every \(y\in Y\), one has \[ f(h(y))=(f\circ h)(y)=y, \] so every element of \(Y\) belongs to the image of \(f\). Thus \(f\) is surjective.

Assume next that \(g\) is a left inverse and \(h\) is a right inverse of \(f\). Then \[ g=g\circ \mathrm{id}_{Y}=g\circ (f\circ h)=(g\circ f)\circ h=\mathrm{id}_{D}\circ h=h, \] so they coincide.

If \(f\) admits an inverse function, then it admits both a left inverse and a right inverse, hence by the first two points it is bijective.

Conversely, assume that \(f\) is bijective. Given \(y\in Y\), surjectivity guarantees the existence of \(x\in D\) such that \(f(x)=y\), and injectivity guarantees that this \(x\) is unique. We may therefore define a function \[ f^{-1}\colon Y\rightarrow D \] by declaring \(f^{-1}(y)\) to be the unique \(x\in D\) such that \(f(x)=y\). By construction, \[ f^{-1}\circ f=\mathrm{id}_{D} \qquad\text{and}\qquad f\circ f^{-1}=\mathrm{id}_{Y}, \] so \(f^{-1}\) is indeed an inverse function.

Uniqueness follows from point 3: any left inverse and right inverse must coincide. Finally, if \(f^{-1}\) exists, then the identities above show that \(f\) is the inverse of \(f^{-1}\), hence \[ \left(f^{-1}\right)^{-1}=f. \]

4 Subsets of real numbers

We need to introduce various types of intervals. These objects help in formalizing the way \(x\) approaches \(x_{0}\).

NoteOpen and closed intervals

Definition 17 Let \(a<b\in\mathbb{R}\cup\{+\infty\}\cup\{-\infty\}\). Here and throughout, inequalities involving \(\pm\infty\) use the usual order on the extended real line. We define the open interval \((a,b)\) as the subset of \(\mathbb{R}\) given by \[ (a,b):= \{x\in\mathbb{R}\,|\quad a< x < b \}. \tag{1}\] If either \(a=-\infty\) or \(b=+\infty\), the interval is said to be unbounded.

When \(a\neq-\infty\) and \(b\neq+\infty\), we define the closed interval \([a,b]\) as \[ [a,b]:= \{x\in\mathbb{R}\,|\quad a\leq x \leq b \}. \]

Intuitively speaking, the interval \((a,b)\) is open because its boundary points are not part of it, while \([a,b]\) is closed because its boundary points are part of it.

Not all intervals are either open or closed. For instance, when \(a\neq-\infty\), we can define the interval \([a,b)\) as \[ [a,b) := \{x\in\mathbb{R}\,|\quad a\leq x < b\}, \] while, when \(b\neq+\infty\), we can define the interval \((a,b]\) as \[ (a,b] := \{x\in\mathbb{R}\,|\quad a < x \leq b\}, \] and it’s clear that these interval are neither open nor closed in the sense of Definition 17

In the following, it will be useful to also consider the symmetric open interval \[ I_{x_{0},\varepsilon}\equiv(x_{0}-\varepsilon, x_{0}+\varepsilon)=\{x\in\mathbb{R}\,|\quad x_{0}-\varepsilon < x < x_{0} + \varepsilon\} \] centered at \(x_{0}\in\mathbb{R}\) with length \(2\varepsilon\) with \(\varepsilon>0\). It is not hard to see that if \(x\in I_{x_{0},\varepsilon}\), then either \(x-x_{0}< \varepsilon\) or \(x_{0} - x <\varepsilon\). It then follows that \(|x-x_{0}|<\varepsilon\), so that \[ I_{x_{0},\varepsilon}=\{x\in\mathbb{R}\,| \quad d(x_{0},x)<\varepsilon\}. \] Therefore, the symmetric open intervals of \(\mathbb{R}\) may be determined through the distance function.

NoteAccumulation point

Definition 18 A point \(x_{0}\in \mathbb{R}\) is said to be a left accumulation point for the subset \(D\) if for every \(r>0\) there exists \(x\in D\) such that \[ x_0-r<x<x_0. \] A point \(x_{0}\in \mathbb{R}\) is said to be a right accumulation point for \(D\) if for every \(r>0\) there exists \(x\in D\) such that \[ x_0<x<x_0+r. \]

A point which is a left (right) accumulation point but not a right (left) accumulation point is called a strict left accumulation point (strict right accumulation point).

A point \(x_0\in\mathbb{R}\) is said to be an accumulation point for \(D\) if for every \(r>0\) there exists \(x\in D\) with \(x\neq x_0\) such that \[ |x-x_0|<r, \] which means it is both a left and right accumulation point.

NoteIsolated point

Definition 19 Let \(D\subseteq\mathbb{R}\) and let \(x_{0}\in D\). We say that \(x_{0}\) is an isolated point of \(D\) if there exists \(r>0\) such that \[ D\cap(x_{0}-r,x_{0}+r)=\{x_{0}\}. \]

NoteAccumulation at infinity

Definition 20 Let \(D\subseteq\mathbb{R}\). We say that \(+\infty\) is a right accumulation point for \(D\) if for every \(R>0\) there exists \(x\in D\) such that \[ x>R. \] We say that \(-\infty\) is a left accumulation point for \(D\) if for every \(R>0\) there exists \(x\in D\) such that \[ x<-R. \]
