Limits and continuity of real-valued functions

Published

October 23, 2025

Modified

March 16, 2026

1 Introduction

2 The definition of limit

Consider the function \(f\colon D\subseteq X\rightarrow Y\), a point \(x_{0}\in X\), and a point \(l\in Y\). The notion of limit we discuss here formalizes the fact that, when everything works, we can make the output of \(f\) stay as close as we want to \(l\) by taking input points that are sufficiently close to \(x_{0}\). In this case, we write \[ \lim_{x\rightarrow x_{0}} f(x)=l, \] and we say that \(l\) is the limit of \(f\colon D\subseteq X\rightarrow Y\) for \(x\) that goes to \(x_{0}\).

The previous intuitive description relies on a very strong hidden assumption: we must be able to say what it means when we say that \(f(x)\) is close to \(l\) and that \(x\) is close to \(x_{0}\). From a purely abstract point of view, the notion of ‘being close to’ works for a very general type of sets, known as metric spaces, as long as a suitable distance function between points can be introduced.

In this course, however, we are mainly concerned with the case \(X=Y=\mathbb{R}\), and the notion of ‘being close to’ has then a very strong and visual intuitive meaning. Indeed, visualizing \(\mathbb{R}\) as the real line, and taking three points \(x_{0},x_{1},x_{2}\in \mathbb{R}\), it would be very hard to disagree with the idea that \(x_{1}\) is closer to \(x_{0}\) than \(x_{2}\) if the ‘distance’ \(\Delta_{1}=|x_{1}-x_{0}|\) between \(x_{1}\) and \(x_{0}\) is smaller than the ‘distance’ \(\Delta_{2}=|x_{2}-x_{0}|\) between \(x_{2}\) and \(x_{0}\), as shown in Figure 1.

The ‘distances’ \(\Delta_{1}\) and \(\Delta_{2}\) are precisely the lengths of the segments joining \(x_{0}\) with \(x_{1}\) and \(x_{0}\) with \(x_{2}\), respectively, as measured with a standard ruler.

NoteEuclidean distance function

Definition 1 The two-point function \(d\colon \mathbb{R}\times\mathbb{R}\rightarrow\mathbb{R}\) given by \[ d(x,y)=\sqrt{(x-y)^{2}}=|x-y| \tag{1}\] is referred to as a Euclidean distance function on \(\mathbb{R}\).

Now that we know what ‘being close to’ means, we can visualize what is the \((\varepsilon-\delta)\)-definition of the limit of a function (see Definition 2 below) when everything works (source: Jason McCullough in Geogebra). The function used in the applet is \(f\colon\mathbb{R}\rightarrow\mathbb{R}\) with \(f(x) = \frac{x^3}{8}\), but can be changed in the input bar. We fix the reference point \(a\in\mathbb{R}\) in the input space by simply dragging it where we want, and visualize the validity of the formal equality \[ \lim_{x\rightarrow x_{0}} f(x)=L \] as follows. The interval \((L-\varepsilon, L+\varepsilon)\) in the output space is depicted as a horizontal blue strip of length \(2\varepsilon\), while the interval \((x_{0}-\delta,x_{0}+\delta)\) in the input space is depicted as a vertical red strip of length \(2\delta\). We can use the sliders to change the value of \(\varepsilon>0\) and \(\delta>0\), and we can see that, whatever the value of \(\varepsilon\) is, we can find a suitable value for \(\delta\) such that \(x\in (x_{0}-\delta,x_{0}+\delta)\) (or, equivalently, \(|x-x_{0}|<\delta\)) implies \(f(x)\in (L-\varepsilon, L+\varepsilon)\) (or, equivalently, \(|f(x)- L|<\epsilon\).

In general, limits do not need to exist, as visualized in the applet below (source: Jason McCullough in Geogebra). This example exploits the oscillating behavior of trigonometric functions, a type of real-valued function that we will be able to properly define only later in the course. The intuitive idea is that, when \(x\) approaches \(0\), the function keeps oscillating taking all values between \(-1\) and \(1\). Consequently, by suitably varying \(\varepsilon\) and \(\delta\) with the sliders, we can see that, as soon as \(\varepsilon\) is smaller than \(1\), there are no \(L\) and no \(\delta>0\) such that \(|x-0|<\delta\) implies \(|f(x)-L|<\varepsilon\).

Now that we have an intuitive and visual understanding of what the notion of limit is, we can proceed to introduce a rigorous definition. Since we can approach the input point \(x_{0}\) from the left, from the right, or from both sides simultaneously, we consider three types of limits.

Note\(\varepsilon\)-\(\delta\) definition of (left/right) limits

Definition 2 Consider the function \(f\colon D\subseteq \mathbb{R}\rightarrow \mathbb{R}\). If \(x_{0}\) is a right accumulation point for \(D\), we say that the formal equality
\[ \lim_{x\rightarrow x_{0}^{+}} f(x)=l \] holds if for every \(\varepsilon>0\) there exists \(\delta>0\) such that \[ x\in D,\quad 0<x-x_{0}<\delta \Longrightarrow |f(x)-l|<\varepsilon . \] In this case, we say that \(l\) is the right limit of \(f\) at \(x_{0}\).

Similarly, if \(x_{0}\) is a left accumulation point for \(D\), we say that the formal equality
\[ \lim_{x\rightarrow x_{0}^{-}} f(x)=l \] holds if for every \(\varepsilon>0\) there exists \(\delta>0\) such that \[ x\in D,\quad 0<x_{0}-x<\delta \Longrightarrow |f(x)-l|<\varepsilon . \] In this case, we say that \(l\) is the left limit of \(f\) at \(x_{0}\).

Finally, if \(x_{0}\) is an accumulation point for \(D\), we say that the formal equality \[ \lim_{x\rightarrow x_{0}} f(x)=l \] holds if for every \(\varepsilon>0\) there exists \(\delta>0\) such that \[ x\in D,\quad 0<|x-x_{0}|<\delta \Longrightarrow |f(x)-l|<\varepsilon . \] In this case, we say that \(l\) is the limit of \(f\) at \(x_{0}\).

Before proceeding further, we must be sure that Definition 2 is well-posed in the sense that a limit, if it exists, is unique.

NoteWell-posedness of limits

Proposition 1 Consider the function \(f\colon D\subseteq\mathbb{R}\rightarrow\mathbb{R}\) and the accumulation point \(x_{0}\) for \(D\). If \[ \begin{split} \lim_{x\rightarrow x_{0}}f(x)&=l \\ \lim_{x\rightarrow x_{0}}f(x)&=m, \end{split} \] then \(l=m\).

Under the obvious modifications, analogous results hold for left and right limits.

Proof:

Assume by contradiction that \(l\neq m\) and set \[ \varepsilon:=\frac{|l-m|}{2}>0. \] From Definition 2, there exist \(\delta_{1},\delta_{2}>0\) such that \[ \begin{split} x\in D,\ 0<|x-x_{0}|<\delta_{1}&\Longrightarrow |f(x)-l|<\varepsilon \\ x\in D,\ 0<|x-x_{0}|<\delta_{2}&\Longrightarrow |f(x)-m|<\varepsilon. \end{split} \] Let \(\delta:=\min(\delta_{1},\delta_{2})\). Since \(x_{0}\) is an accumulation point for \(D\), there exists \(x\in D\) such that \(0<|x-x_{0}|<\delta\). For this \(x\), both inequalities above hold, and therefore \[ |l-m|\leq |l-f(x)|+|f(x)-m|<\varepsilon+\varepsilon=|l-m|, \] which is impossible. Hence \(l=m\).

The case of left and right limits can be proved analogously.

We now pass to compute limits in three very instructive cases.

TipThree simple examples

Example 1 Let us start considering the function \(f\colon \mathbb{R}\rightarrow\mathbb{R}\) given by \(f(x)=c\) and prove that \[ \lim_{x\rightarrow x_{0}} f(x)= c = f(x_{0}) \tag{2}\] for every \(x_{0}\in\mathbb{R}\). According to Definition 2, we need to prove that, for every \(\varepsilon>0\), there is \(\delta>0\) such that \(|x-x_{0}|<\delta\) implies \(|f(x)-c|<\varepsilon\).

Since \(f(x)=f(y)=c\) for all \(x,y\in\mathbb{R}\), it follows that \(|f(x) - c|=0<\varepsilon\) for every \(x\in\mathbb{R}\) and every \(\varepsilon>0\). In particular, fixing \(\varepsilon,\delta>0\), the condition \(|x -x_{0}|<\delta\) trivially implies \(|f(x)-c|<\varepsilon\) which is precisely what we had to prove. Note that, in this case \(\delta=\delta\), which means that it does not depend on \(\varepsilon\).

Now, let us consider the function \(f\colon \mathbb{R}\rightarrow\mathbb{R}\) given by \(f(x)=x + a\), and prove that \[ \lim_{x\rightarrow x_{0}} f(x)= x_{0} + a=f(x_{0}) \tag{3}\] for every \(x_{0}\in\mathbb{R}\). According to Definition 2, we need to prove that, for every \(\varepsilon>0\), there is \(\delta>0\) such that \(|x-x_{0}|<\delta\) implies \(|f(x)-f(x_{0})|<\varepsilon\).

By the very definition of \(f\), it holds \(|f(x) - (x_{0}+a)|=|x - x_{0}|\). Taking \(\delta< \varepsilon\), we get that \(|x - x_{0}|<\delta\) implies \(|f(x) - f(x_{0})|<\varepsilon\) as desired. Note that, unlike what happens in the case of the constant function above, \(\delta_\varepsilon\) depends on \(\varepsilon\) because it must be \(\delta<\varepsilon\).

Finally, let us consider the function \(f\colon \mathbb{R}\rightarrow\mathbb{R}\) given by \(f(x)=x^{2}\), and prove that \[ \lim_{x\rightarrow x_{0}} f(x)= x_{0}^{2}= f(x_{0}) \tag{4}\] for every \(x_{0}\in\mathbb{R}\). According to Definition 2, we need to prove that, for every \(\varepsilon>0\), there is \(\delta>0\) such that \(|x-x_{0}|<\delta\) implies \(|f(x)-x_{0}^{2}|<\varepsilon\).

It is \(|f(x)-x_{0}^{2}|=|x^{2} - x_{0}^{2}|\), and, using the properties of the absolute value, we have \[ |x^{2} - x_{0}^{2}| =|(x+x_{0})(x-x_{0})|\leq |x + x_{0}||x-x_{0}|. \] Moreover, it holds \[ | x+ x_{0}| =|x - x_{0} + 2x_{0}|\leq |x - x_{0}| + 2|x_{0}|, \] so that \(|x - x_{0}|<\delta\) implies \[ |x^{2} - x_{0}^{2}|\leq (|x - x_{0}| + 2|x_{0}|)\,|x-x_{0}| < ( \delta+2|x_{0}|)\,\delta. \] Therefore, to get \(|f(x)-x_{0}^{2}|=|x^{2} - x_{0}^{2}|<\varepsilon\), we must ensure that \[ \delta^{2} + 2|x_{0}| \delta - \varepsilon<0 . \] Solving the previous quadratic equation in the variable \(\delta\) we obtain the condition \[ 0 < \delta < \sqrt{x^{2}_{0} + \varepsilon} -|x_{0}| = \sqrt{x^{2}_{0} + \varepsilon} - \sqrt{x^{2}_{0}}. \] Note that the way in which \(\delta\) depends on \(\varepsilon\) is more complex than in the case of the linear function above.

In Definition 2, three types of limits are considered because we can approach the input point \(x_{0}\) from the left, from the right, or from both sides simultaneously. In the last case, it is reasonable to ask if the three types of limits agree. In the exercise below, you are asked to prove that this is indeed the case.

Consequently, the function \(f\colon (0,3)\subset\mathbb{R}\rightarrow\mathbb{R}\) given by \(f(x)=x+3\) and the function \(g\colon (-1,2)\subset\mathbb{R}\rightarrow\mathbb{R}\) given by \(g(x)=x+3\) are different functions. 3 Continuity

Recall that the point \(x_{0}\) in Definition 2 is not necessarily a point in the domain \(D\) of the function \(f\) under consideration. Therefore, limits describe the behavior of \(f\) near \(x_{0}\) independently of the value of \(f\) at \(x_{0}\), which may not exist at all if \(x_{0}\notin D\). However, we may be interested in understanding what happens to \(f\) when we consider input points in \(D\) that are close to the input point \(x_{0}\in D\). In this case, what we need is the notion of continuity.

Continuity is meant to formalize a very concrete idea: small changes in the input should produce small changes in the output. In other words, if we want to keep the values of \(f(x)\) within a prescribed tolerance \(\varepsilon>0\) from the reference value \(f(x_{0})\), we should be able to enforce this by restricting \(x\) to be sufficiently close to \(x_{0}\).

This may sound almost identical to the definition of limit in Definition 2, and one could try to define continuity at \(x_{0}\) by requiring that \[ \lim_{x\rightarrow x_{0}} f(x)=f(x_{0}). \] However, this formulation only makes sense when \(x_{0}\in D\) is an accumulation point of \(D\) (see Definition 2), which is not always the case (see below). For this reason, we introduce continuity directly via an \(\varepsilon\)-\(\delta\) condition comparing \(f(x)\) to \(f(x_{0})\).

NoteContinuity

Definition 3 Let \(x_{0}\in D\subseteq \mathbb{R}\). The function \(f\colon D\subseteq \mathbb{R}\rightarrow \mathbb{R}\) is said to be continuous at \(x_{0}\) if, for every \(\varepsilon>0\), there exists \(\delta>0\) such that \[ x\in D,\quad |x-x_{0}|<\delta \Longrightarrow |f(x)-f(x_{0})|<\varepsilon. \]

If \(x_{0}\) is a right accumulation point for \(D\), \(f\) is right continuous at \(x_{0}\) if, for every \(\varepsilon>0\), there exists \(\delta>0\) such that \[ x\in D,\quad 0<x-x_{0}<\delta \Longrightarrow |f(x)-f(x_{0})|<\varepsilon. \]

If \(x_{0}\) is a left accumulation point for \(D\), \(f\) is left continuous at \(x_{0}\) if, for every \(\varepsilon>0\), there exists \(\delta>0\) such that \[ x\in D,\quad 0<x_{0}-x<\delta \Longrightarrow |f(x)-f(x_{0})|<\varepsilon. \]

The function \(f\colon D\subseteq \mathbb{R}\rightarrow \mathbb{R}\) is said to be continuous on \(D\) if it is continuous at every \(x_{0}\in D\).

NoteContinuity and limits at accumulation points

Proposition 2 Let \(f\colon D\subseteq \mathbb{R}\rightarrow \mathbb{R}\) and let \(x_{0}\in D\) be an accumulation point for \(D\). Then \(f\) is continuous at \(x_{0}\) in the sense of Definition 3 if and only if \[ \lim_{x\rightarrow x_{0}}f(x)=f(x_{0}). \]

Analogous statements hold for left continuity and left limits (when \(x_{0}\) is a left accumulation point), and for right continuity and right limits (when \(x_{0}\) is a right accumulation point).

Proof:

Assume first that \(f\) is continuous at \(x_{0}\). Given \(\varepsilon>0\), let \(\delta>0\) be as in Definition 3: \[ x\in D,\quad |x-x_{0}|<\delta \Longrightarrow |f(x)-f(x_{0})|<\varepsilon. \] In particular, for every \(x\in D\) with \(0<|x-x_{0}|<\delta\), the same inequality holds. Hence, by Definition 2, \[ \lim_{x\rightarrow x_{0}}f(x)=f(x_{0}). \]

Conversely, assume \[ \lim_{x\rightarrow x_{0}}f(x)=f(x_{0}). \] Given \(\varepsilon>0\), Definition 2 provides \(\delta>0\) such that \[ x\in D,\quad 0<|x-x_{0}|<\delta \Longrightarrow |f(x)-f(x_{0})|<\varepsilon. \] Now take any \(x\in D\) with \(|x-x_{0}|<\delta\). If \(x\neq x_{0}\), the previous implication applies. If \(x=x_{0}\), then \(|f(x)-f(x_{0})|=0<\varepsilon\). Therefore \[ x\in D,\quad |x-x_{0}|<\delta \Longrightarrow |f(x)-f(x_{0})|<\varepsilon, \] which is exactly continuity at \(x_{0}\).
WarningContinuity at isolated points

Remark 1. If \(x_{0}\in D\) is an isolated point of \(D\), then every function \(f\colon D\rightarrow\mathbb{R}\) is continuous at \(x_{0}\) in the sense of Definition 3. By definition of isolated point, there exists \(\delta>0\) such that \[ D\cap(x_{0}-\delta,x_{0}+\delta)=\{x_{0}\}, \] so that \[ x\in D,\quad |x-x_{0}|<\delta \Longrightarrow x=x_{0} \Longrightarrow |f(x)-f(x_{0})|=0. \] In this case, \(\lim_{x\rightarrow x_{0}}f(x)\) is not defined in the sense of Definition 2 because \(x_{0}\) is not an accumulation point of \(D\).

CautionContinuity is equivalent to simultaneous left and right continuity

Solution: Use Exercise 1 and Proposition 2.

It is informally said that a function \(f\colon D\subseteq\mathbb{R}\rightarrow\mathbb{R}\) is a continuous function if its graph can be drawn on paper without lifting the pen/pencil. We now try to make this informal statement precise by working our way to the intermediate value theorem below. First, we prove the so-called sign-preserving property of continuous functions.

4 Algebraic manipulations of limits and continuous functions

From the quadratic case in Example 1, it should be clear that computing limits following Definition 2 is not going to be an easy task for arbitrarily complex functions. Luckily for us, some mathematicians were able to prove general propositions that allow to exploit simple cases to solve more complex ones.

To understand how one may envision such general propositions, let us keep in mind the results obtained in Example 1. Setting \(f(x)=x +c\), \(g(x)=x\), and \(h(x)=c\), we see that Equation 2 and Equation 3 (once with \(a=c\) and once with \(a=0\)) imply \[ \lim_{x\rightarrow x_{0}} f(x)=\left(\lim_{x\rightarrow x_{0}} g(x) \right) + \left(\lim_{x\rightarrow x_{0}} h(x)\right), \] which means that the limit of the sum is the sum of the limits. Moreover, setting \(f(x)=x^{2}\) and \(g(x)=x=h(x)\), we also see that Equation 3 and Equation 4 imply \[ \lim_{x\rightarrow x_{0}} f(x)=\left(\lim_{x\rightarrow x_{0}} g(x)\right)\;\left(\lim_{x\rightarrow x_{0}} h(x)\right), \] which means that the limit of the product is the product of the limits.

A question then immediately arises: how general are these facts? It turns out that they are quite general.

NoteAlgebraic manipulations of limits

Proposition 4 Let \(\alpha,\beta\in\mathbb{R}\), and consider the functions \(f,g\colon D\subseteq \mathbb{R}\rightarrow \mathbb{R}\). If \[ \lim_{x\rightarrow x_{0}}f(x)=L_{1} \mbox{ and } \quad \lim_{x\rightarrow x_{0}}g(x)=L_{2} \] in the sense of Definition 2, then \[ \begin{split} \lim_{x\rightarrow x_{0}} \left(\alpha \,f + \beta \,g \right)(x) &=\lim_{x\rightarrow x_{0}} \alpha \,f (x) + \lim_{x\rightarrow x_{0}} \beta \, g(x) = \alpha\,L_{1} + \beta \,L_{2} \\ & \\ \lim_{x\rightarrow x_{0}} \left((\alpha \,f)\cdot(\beta \,g)\right) (x) & =\left(\lim_{x\rightarrow x_{0}} \alpha \,f(x)\right)\left(\lim_{x\rightarrow x_{0}} \beta \,g(x)\right)= \alpha\,L_{1}\,\beta \,L_{2} \end{split} \tag{5}\] If \(\beta,\,L_{2}\neq 0\) and there exists \(\delta_{0}>0\) such that \[ x\in D,\quad 0<|x-x_{0}|<\delta_{0}\Longrightarrow g(x)\neq 0 \] then \[ \begin{split} \lim_{x\rightarrow x_{0}}\,\left(\frac{\alpha \,f}{\beta \,g}\right)(x)&=\frac{\lim_{x\rightarrow x_{0} }\alpha \,f(x)}{\lim_{x\rightarrow x_{0} }\beta \,g(x)} =\frac{\alpha L_{1}}{\beta L_{2}}. \end{split} \tag{6}\]

Under suitable modifications, analogous conclusions hold for left and right limits.

Proof:

Let us start with the weighted sum of two functions. From Definition 2, for any \(\varepsilon_{1},\varepsilon_{2}>0\) there are \(\delta_{1},\delta_{2}>0\) such that \[ \begin{split} x\in D,\ 0<|x-x_{0}|<\delta_{1}&\Rightarrow |f(x) -L_{1}|<\varepsilon_{1} \\ x\in D,\ 0<|x-x_{0}|<\delta_{2}&\Rightarrow |g(x) -L_{2}|<\varepsilon_{2}. \end{split} \tag{7}\] Consequently, if \(x\in D\) and \(0<|x-x_{0}|<\mathrm{min}(\delta_{1},\delta_{2})\), it holds \[ |\alpha f(x)+\beta g(x)-\alpha L_{1}-\beta L_{2}| \leq |\alpha|\,|f(x)-L_{1}| + |\beta|\,|g(x)-L_{2}| < |\alpha|\,\varepsilon_{1}+|\beta|\,\varepsilon_{2}. \] For every \(\varepsilon>0\), take \[ \varepsilon_{1}:=\min\left\{1,\frac{\varepsilon}{2(|\alpha|+1)}\right\},\qquad \varepsilon_{2}:=\min\left\{1,\frac{\varepsilon}{2(|\beta|+1)}\right\}. \] and therefore \[ |\alpha|\,\varepsilon_{1}+|\beta|\,\varepsilon_{2}\le \frac{\varepsilon}{2}\left(\frac{|\alpha|}{1+|\alpha|}+\frac{|\beta|}{1+|\beta|}\right)<\varepsilon. \] which means that \(\alpha L_{1} + \beta L_{2}\) is the limit at \(x_{0}\) of \((\alpha f+\beta g)(x)=\alpha f(x) + \beta g(x)\) according to Definition 2.

Now passing to the product of two functions, we work directly in the weighted case: \[ \begin{split} |(\alpha f)(x)(\beta g)(x)-\alpha\beta L_{1}L_{2}|&=|\alpha\beta|\,|f(x)g(x)-L_{1}L_{2}| \\ &=|\alpha\beta|\,\mid (f(x) -L_{1} + L_{1})(g(x) -L_{2} +L_{2}) -L_{1}L_{2}\mid \\ &=|\alpha\beta|\,\mid (f(x) -L_{1})(g(x)-L_{2}) + L_{1}(g(x)-L_{2}) + (f(x)-L_{1})L_{2}\mid \\ &\le |\alpha\beta|\big(\mid (f(x) -L_{1})(g(x)-L_{2})\mid + \mid L_{1}(g(x)-L_{2})\mid + \mid(f(x)-L_{1})L_{2}\mid\big)\\ &< |\alpha\beta|\left(\varepsilon_{1}\varepsilon_{2} + |L_{1}|\,\varepsilon_{2} + |L_{2}|\,\varepsilon_{1}\right). \end{split} \] Given \(\varepsilon>0\), choose \[ \eta':=\min\left\{1,\frac{\varepsilon}{(1+|L_{1}|+|L_{2}|)(|\alpha\beta|+1)}\right\}, \] and set \(\varepsilon_{1}=\varepsilon_{2}=\eta'\). Then \[ \varepsilon_{1}\varepsilon_{2} + |L_{1}|\,\varepsilon_{2} + |L_{2}|\,\varepsilon_{1} \leq \eta'(\eta'+|L_{1}|+|L_{2}|)\leq \eta'(1+|L_{1}|+|L_{2}|)\leq \frac{\varepsilon}{|\alpha\beta|+1}, \] and from this we deduce \[ \left|(\alpha f)(x)(\beta g)(x)-\alpha\beta L_{1}L_{2}\right| \leq |\alpha\beta|\left(\varepsilon_{1}\varepsilon_{2}+|L_{1}|\varepsilon_{2}+|L_{2}|\varepsilon_{1}\right) \leq \frac{|\alpha\beta|}{|\alpha\beta|+1}\,\varepsilon < \varepsilon. \] Therefore \((\alpha f)(x)(\beta g)(x)= (\alpha f)(x)\,(\beta g)(x)\) has limit \(\alpha\beta L_{1}L_{2}\) at \(x_0\). Scalar multiplication is a subcase: taking \(g\equiv 1=\beta\) (so that \(L_{2}=1\)) gives \[ \lim_{x\to x_{0}}\alpha f(x)=\alpha L_{1}. \]

For the quotient case, set \(h(x):=\beta g(x)\). By the scalar multiplication result proved above, we already know that \[ \lim_{x\to x_{0}}h(x)=\beta L_{2}. \] From the hypothesis on \(\beta g\), choose \(\delta_{0}>0\) such that \[ x\in D,\ 0<|x-x_{0}|<\delta_{0}\Longrightarrow h(x)\neq 0, \] equivalent to \(g(x)\neq 0\) since \(\beta\neq 0\). If we prove \[ \lim_{x\to x_{0}}\frac{1}{h(x)}=\frac{1}{\beta L_{2}}, \] then the quotient follows by the product formula already proved: \[ \lim_{x\to x_{0}}\left(\frac{\alpha f}{\beta g}\right)(x) =\lim_{x\to x_{0}}(\alpha f)(x)\cdot\lim_{x\to x_{0}}\frac{1}{h(x)} =\frac{\alpha L_{1}}{\beta L_{2}}. \]

Fix \(\varepsilon>0\) and define \[ \eta:=\min\left\{1,\frac{|\beta L_{2}|}{2},\frac{\varepsilon |\beta L_{2}|^{2}}{2}\right\}. \] By definition of limit there is \(\delta_{1}>0\) such that \(x\in D\) and \(0<|x-x_{0}|<\delta_{1}\) imply \(|h(x)-\beta L_{2}|<\eta\). Set \(\delta:=\min\{\delta_{0},\delta_{1}\}\). For \(x\in D\) with \(0<|x-x_{0}|<\delta\), we have \(h(x)\neq 0\) (from \(\delta_{0}\)) and \[ |h(x)-\beta L_{2}|<\eta\le \frac{|\beta L_{2}|}{2}. \] By the reverse triangle inequality, \[ \left||h(x)|-|\beta L_{2}|\right|\le |h(x)-\beta L_{2}|, \] hence \[ |h(x)|\ge |\beta L_{2}|-|h(x)-\beta L_{2}|. \] Therefore \[ |h(x)|\ge |\beta L_{2}|-|h(x)-\beta L_{2}| \ge\frac{|\beta L_{2}|}{2}. \] Thus \[ \left|\frac{1}{h(x)}-\frac{1}{\beta L_{2}}\right| =\frac{|h(x)-\beta L_{2}|}{|h(x)|\,|\beta L_{2}|} \le\frac{2\,|h(x)-\beta L_{2}|}{|\beta L_{2}|^{2}} <\frac{2\eta}{|\beta L_{2}|^{2}} \le\varepsilon. \] Therefore \[ \lim_{x\to x_{0}}\frac{1}{h(x)}=\frac{1}{\beta L_{2}}, \] and the quotient formula is proved.

The case of left and right limits should be easy to obtain by following and suitably adapting the previous steps.

Recalling the summation and product notation \[ \begin{split} \sum\limits_{j=1}^{n} A_{j}&\equiv A_{1} + A_{2} + \cdots + A_{n} \\ \prod_{j=1}^{n}A_{j}&\equiv A_{1}\,A_{2}\,\cdots\,A_{n} , \end{split} \] where \((A_{1},\cdots,A_{n})\) can be a finite sequence of numbers or functions, we can use the previous results together with the associativity property for function sums and products to solve the following exercise.

We are slowly building quite a useful toolbox for computing limits and understanding continuity of real-valued functions. However, we are still unable to prove that the function \(f\colon\mathbb{R}\rightarrow \mathbb{R}\) given by \(f(x)=\sqrt{x^{2} +3}\) is continuous without verifying that Definition 3 is fulfilled, and this would require us to compute a lot of limits using Definition 2.

Motivated by a powerful urge to avoid computing limits using Definition 2 unless physically forced to, we look for alternatives. We thus note that the function \(f\) introduced above is nothing but the composite function \(f=g\circ h\), with \(g\colon\mathbb{R}\rightarrow \mathbb{R}\) given by \[ g(y)=\sqrt{y}, \] and \(h\colon\mathbb{R}\rightarrow\mathbb{R}\) given by \[ h(x)=x^{2}+3. \] Moreover, Exercise 6 and Exercise 7 guarantee that both \(g\) and \(h\) are continuous everywhere in their domain.

Wouldn’t it be nice if the continuity of \(g\) and \(h\) were enough to guarantee the continuity of \(f\)? The following two propositions make us happy because they answer the previous question with a solid ‘yes’.

NoteLimit of composite functions

Proposition 7 Consider the functions \(f\colon D\subseteq \mathbb{R} \rightarrow \mathbb{R}\) and \(g\colon D'\subseteq \mathbb{R} \rightarrow \mathbb{R}\), and let \(x_{0}\) be an accumulation point for \(D'\). Suppose that \[ \lim_{x\rightarrow x_{0}}g(x)=l \tag{9}\] where the first limit is taken in \(D'\), and \(l\in D\), and \[ \lim_{y\rightarrow l} f(y) =L . \tag{10}\] The equality \[ \lim_{x\rightarrow x_{0}} f\circ g(x)=L \] holds if either one of the following additional assumptions are met:

  1. \(f\) is continuous at \(y=l\);
  2. there is an open interval \(I\) centered at \(x_{0}\) such that \(I\setminus\{x_{0}\}\subseteq D'\) and \(g(x)\neq l\) for every \(x\in I\setminus\{x_{0}\}\).

Analogous results hold for right/left limits.

Proof:

From Equation 10, given \(\varepsilon>0\), it follows that there is \(\eta>0\) for which \[ 0<|y-l|<\eta \implies |f(y)-L|<\varepsilon, \tag{11}\] On the other hand, Equation 9 implies that, given the same \(\eta>0\) as before, there is \(\delta>0\) such that \[ 0<|x-x_{0}|<\delta \implies |g(x) - l|<\eta. \tag{12}\] Setting \(y=g(x)\), Equation 12 leads to \(|g(x)-l|<\eta\), while Equation 11 states that \(0<|y-l|=|g(x)-l|<\eta\) implies \(|f(y)-L|=|f(g(x))-L|<\varepsilon\), and it does not necessarily hold that \(|g(x)-l|<\eta\) implies \(0<|y-l|<\eta\) because \(y=g(x)\) may be equal to \(l\). See Exercise 8 for more details. We thus need to assume something more to obtain the desired result.

  1. In this case, \(L=f(l)\) because \(f\) is continuous at \(l\), and thus \(|f(y) -L|=|f(y) -f(l)|<\varepsilon\) even when \(y=g(x)=l\), and the result follows.
  2. In this case, we can take \(\delta\) sufficiently small so that \(0<|x-x_{0}|<\delta\) implies \(x\in I\) and thus \(g(x)\neq l\) by assumption. Consequently, it holds \[ 0<|x-x_{0}|<\delta \implies 0<|g(x) - l|<\eta \implies |f(g(x)) -L|<\varepsilon, \] as desired.
CautionComposition can be tricky

Exercise 8 Let \(f,g\colon\mathbb{R}\rightarrow\mathbb{R}\) be given by \[ f(x)=g(x)=\left\{\begin{matrix} 0 & \mbox{ if } x\neq 0 \\ 1 & \mbox{ if } x= 0 .\end{matrix}\right. \] Show that this example does not satisfy the hypotheses of Proposition 7, and explain why.

Solution: Since \(f(x)=g(x)=0\) for \(x\neq 0\), it holds \[ \lim_{y\rightarrow 0} f(y)=0 =\lim_{x\rightarrow 0} g(x) . \] On the other hand, the composite function \(h=f\circ g\) is \[ h(x)=\left\{\begin{matrix} 1 & \mbox{ if } x\neq 0 \\ 0 & \mbox{ if } x= 0,\end{matrix}\right. \] so that \[ \lim_{x\rightarrow 0} h(x)= 1 = \lim_{x\rightarrow 0} (f\circ g)(x). \] Therefore, there is no contradiction. The issue is that the naive rule \[ \lim_{x\to x_{0}} f(g(x))=f\!\left(\lim_{x\to x_{0}}g(x)\right) \] is not always valid without additional assumptions. Here, \(f\) is not continuous at \(0\), and \(g(x)=0\) for every \(x\neq 0\) close to \(0\), so condition (2) in Proposition 7 also fails.

Proposition 7 immediately implies that continuous functions behave well when composed among themselves.

NoteComposition of continuous functions

Proposition 8 Consider the functions \(f\colon D\subseteq \mathbb{R} \rightarrow \mathbb{R}\) and \(g\colon D'\subseteq \mathbb{R} \rightarrow \mathbb{R}\). If \(g\) is continuous at \(x_{0}\) and \(f\) is continuous at \(g(x_{0})\) then the composite function \(f\circ g\) is continuous at \(x_{0}\).

Proof: Follow Definition 3 and apply Proposition 7.

  1. Calculate the left and right limits \(\lim_{x\to0^\pm}\frac{|x|}{x}=\frac{\sqrt{x^2}}{x}\) and decide whether the limit at \(0\) exists.
Solution

For \(x\neq0\) it holds \[ \frac{|x|}{x}= \begin{cases} 1 & \text{if } x>0,\\ -1 & \text{if } x<0. \end{cases} \] Therefore, for \(x<0\) and \(x>0\), \(f(x)\) is the restriction of the constant function \(-1\) and \(1\), respectively, so that \[ \lim_{x\to 0^+}\frac{|x|}{x}=1, \qquad \lim_{x\to 0^-}\frac{|x|}{x}=-1. \] If the limit existed, both left and right limits would coincide by Proposition 1, contradicting the two different values above. Therefore, the limit at \(0\) does not exist.

  1. Let \[ f(x)=\begin{cases} 0 & \text{if } x\in\mathbb{Q},\\ 1 & \text{if } x\notin\mathbb{Q}. \end{cases} \] Prove that \(\lim_{x\to x_0}f(x)\) does not exist for any \(x_0\in\mathbb{R}\).
Solution

Assume \(\lim_{x\to x_0}f(x)=L\). Choose \(\varepsilon=\frac12\). By the limit definition, there must be \(\delta>0\) such that \(|f(x)-L|<\frac12\) whenever \(0<|x-x_0|<\delta\). But any interval \((x_0-\delta,x_0+\delta)\) contains both rational and irrational points, so we can find \(q\in\mathbb{Q}\) and \(r\notin\mathbb{Q}\) with this property. Then \(f(q)=0\) and \(f(r)=1\), hence \[ |f(q)-L|<\frac12,\qquad |f(r)-L|<\frac12. \] So \(L\) is within \(\frac12\) of both \(0\) and \(1\), impossible. Therefore the limit does not exist.

  1. Let \[ g(x)=\begin{cases} 0 & \text{if } x\in\mathbb{Q},\\ x & \text{if } x\notin\mathbb{Q}. \end{cases} \] Show that \(\lim_{x\to 0}g(x)=0\), and determine for which \(x_0\neq 0\) the limit can exist.
Solution

To show \(\lim_{x\to 0}g(x)=0\), let \(\varepsilon>0\).
If \(x\in\mathbb{Q}\), then \(g(x)=0\), so \(|g(x)-0|=0<\varepsilon\).
If \(x\notin\mathbb{Q}\), then \(g(x)=x\), so \(|g(x)-0|=|x|<\varepsilon\) whenever \(|x|<\varepsilon\).
Hence for \(\delta=\varepsilon\), Definition 2 gives \(\lim_{x\to0}g(x)=0\).

Now let \(x_0\neq0\). Take \(\varepsilon=|x_0|/2\). For any \(\delta>0\), set \(\delta_0=\min\{\delta,|x_0|/2\}\) and pick a rational \(q\) and an irrational \(r\) such that \(0<|q-x_0|<\delta_0\) and \(0<|r-x_0|<\delta_0\). Then \(g(q)=0\), while \(g(r)=r\). Since \[ |r| \geq ||x_0|-|r-x_0|| > \frac{|x_0|}{2}=\varepsilon, \] there is no single \(L\) such that \(|g(r)-L|<\varepsilon\) together with \(|g(q)-L|<\varepsilon\). Thus \(\lim_{x\to x_0}g(x)\) does not exist for \(x_0\neq0\).

  1. Let \[ h(x)=\begin{cases} 0 & \text{if } x\le 0,\\ 1 & \text{if } x>0. \end{cases} \] Compute the left and right limits at \(x_0=0\), and decide whether \(h\) is continuous, left continuous, or right continuous at \(0\).
